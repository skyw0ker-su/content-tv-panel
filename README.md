# Показ контента на инфопанелях

Система для показа видео, аудио и изображений на ТВ‑панелях.

- Каждый мини‑ПК на Astra Linux SE 1.8+ подключён к ТВ по HDMI.
- Агент забирает с сервера расписание и плейлист, скачивает контент в локальный кэш и играет его в полноэкранном режиме через VLC (libVLC).
- Сервер хранит медиа, плейлисты и расписания, показывает статус экранов. Превью того, что воспроизводится, запрашивается админом по требованию.

## Состав

```
server/   сервер: API (FastAPI), PostgreSQL, загрузка медиа, веб‑админка
agent/    агент для мини‑ПК: синхронизация, воспроизведение через VLC, пакет .deb
docs/     архитектура и план (копия из общего плана)
```

## Архитектура (кратко)

- **Сервер:** FastAPI, PostgreSQL, Docker Compose. Модели: медиа, плейлисты, элементы плейлиста, расписания, устройства.
- **Агент:** регистрация по токену, манифест с хешами, кэш, плейлист по расписанию, heartbeat со статусом (текущий элемент, версия плейлиста, заполненность кэша). Превью кадра не отправляется само: сервер запрашивает снимок по команде из админки, агент делает кадр из VLC и отправляет его один раз.
- **Работа без сети:** агент продолжает играть последнее полученное расписание из кэша.
- **Астра:** агент ставится пакетом .deb со службой systemd; Python и VLC из репозиториев Astra.

## Запуск

Сервер (нужен `ADMIN_TOKEN`; без него админские методы отвечают 503):

```
cd server
pip install -r requirements-dev.txt
ADMIN_TOKEN=change-me python -m pytest          # тесты
ADMIN_TOKEN=change-me uvicorn app.main:app      # локально, SQLite по умолчанию
docker compose up --build                       # сервер + PostgreSQL (нужны POSTGRES_PASSWORD и ADMIN_TOKEN)
```

Агент (на мини‑ПК, переменные из `/etc/signage-agent/agent.env`, пример в `agent/packaging/`):

```
cd agent
pip install -e ".[dev]"
python -m pytest                                # тесты расписания и кэша
```

## Что уже есть

- Сервер: загрузка медиа (хеш SHA‑256), плейлисты с версиями, расписания (дни недели, окна, в том числе через полночь, приоритет, даты действия), устройства с токенами, манифест с ETag, heartbeat, превью по запросу админа.
- Агент: выбор плейлиста по расписанию локально, кэш с проверкой хеша, работа по последнему манифесту без сети, воспроизведение через VLC, снимок кадра по запросу, unit systemd.

## Что не готово

- Сборка пакета `.deb` и подпись под замкнутую программную среду Astra.
- Веб‑админка (сейчас только API).
- Проверка воспроизведения и снимка VLC на реальном мини‑ПК с Astra: тесты покрывают расписание и кэш, а не libVLC.
- Миграции БД (сейчас `create_all`).
